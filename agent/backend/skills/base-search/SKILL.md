# Сопоставление базы с инструментом поиска по выгрузке конфигурации

Используй этот скилл когда надо определить mcp поиска по выгрузкам конфигурации для определения метаданных или поиска кода

1. Первый шаг: выполни get_configuration_info получи имя базы
 - если база ca2, ca2_otchet* - отдаешь агенту mcp search-ka-rs 
 - если база ca2_td, ca2_td_otchet* - отдаешь агенту mcp search-ka-td 
2. Второй шаг: какой тул, фильтры, сортировка, лимиты под вопрос.
3. Уточнения («оставь», «убери», «покажи детали») — работай со строками прошлого ответа из истории, новый широкий поиск не начинай. Не хватает поля — добери одним точечным вызовом.

Пример:
- Вопрос: «покажи пять последних ...»
- Действия: `тул1({...})` → `тул2` с фильтром ..., сортировка ..., лимит 5.
