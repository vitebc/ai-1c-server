# 1С:Комплексная автоматизация 2. Новое в версии 2.5.8.263

Дата выхода релиза: 05.08.2022

## Управленческий учет затрат и финансовый результат

С целью оптимизации выполнения процедуры **Закрытие месяца** в части подготовки данных для
детализации себестоимости внесены изменения в алгоритмы системы.

Обеспечена возможность выключить формирование
полных данных для детализации себестоимости и обрабатывать только данные,
необходимые для целей НДС, при выполнении платформенного метода решения системы
линейных уравнений (далее – СЛУ).

В блоке **Учетная
политика финансового учета** учетной политики организации
настройка **Детализировать дополнительные расходы в себестоимости
товаров по статьям расходов** переименована в **Детализировать материальные и постатейные затраты в себестоимости
товаров**.

![](image001.png?_=0000B75F0362AC0F-v10)

Отменено обязательное включение указанной
настройки при включении опции **Раздельный учет товаров по
налогообложению НДС** в блоке **Настройки
учета НДС** учетной политики организации. Настройка **Детализировать материальные и постатейные затраты в себестоимости
товаров** теперь включается вручную пользователем.

Если настройка **Детализировать
материальные и постатейные затраты в себестоимости товаров** в
учетной политике организации выключена, тогда при решении СЛУ в рамках операции
по формированию данных для детализации себестоимости процедуры **Закрытие месяца** обрабатываются только данные,
необходимые для целей НДС. Расшифровка себестоимости до исходных затрат в
отчетах при выключенной настройке **Детализировать материальные и постатейные
затраты в себестоимости товаров** не предполагается.
