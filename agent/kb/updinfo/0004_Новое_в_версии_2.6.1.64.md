## Казначейство

### Загрузка выписки по счету цифрового рубля

Счет 53 «Счет цифрового
рубля» добавлен в план счетов бухгалтерского учета, как предопределенный и
интегрирован в документы, отчеты и справочники.

![](image001.png?_=0001FF962B833294-v10)

Бухгалтерская отчетность
формируется с учетом счета 53 «Счет цифрового рубля».

Доработана загрузка выписки:

* Осуществляется распознавание операций цифрового рубля.
* Подбор бюджетных реквизитов для операций перечисления в бюджет.
* Новый счет
  цифрового рубля контрагента создается автоматически в процессе загрузки
  выписки, если включена настройка **Создавать контрагентов
  автоматически**, (см. рабочее место **Загрузка выписки
  / зачисления на лицевые счета** - кнопка **Настройки**).

Новый счет цифрового рубля
организации создается вручную.

При создании карточки нового
банковского счета цифрового рубля организации подставляется автоматически счет
учета 53 «Счет цифрового рубля». При необходимости его можно изменить.

![](image003.png?_=0001C79AD1F2EDA7-v10)

#### Особенности загрузки и выгрузки выписки по цифровому рублю

Для загрузки используются
файлы в формате обмена Центральный Банк России. Поле **Формат
обмена** не отображается. Исключено отображение настроек прямого обмена.

![](image005.png?_=0001A6F520020282-v10)

Операции с участием счета
цифрового рубля не могут передаваться в банк через обычную выписку, для этого
требуется использовать специальный механизм обмена, которые обеспечивают
кредитные организации, поддерживающие операции с цифровым рублем.

Счет цифрового рубля и
операции с цифровым рублем исключены из выгрузки.

Из списка счетов на выгрузку
исключаются счета цифрового рубля

![](image007.png?_=0001B3E3F7E849C7-v10)

Из списка документов по
обычному расчетному счету исключаются документы, где одной из сторон указан
счет цифрового рубля.

![](image009.png?_=0001FAA7CAE16685-v10)

В рабочем месте загрузки выписки
применяется установленная **Настройка обмена** для
выбора файла xml.

![](image011.png?_=00042DE51B97D898-v10)

**Списание
безналичных денежных** средств с
типом **Платежное поручение** или **Поступление безналичных денежных средств** с типом **Платежное требование** с цифровым рублем оформляются пользователем через личный кабинет
банка, не через систему.

В процессе загрузки выписки документы
оплаты создаются автоматически по перечисленным ниже операциям выписки:

* Отражение оплаты налогов через цифровой рубль.
* Обработка комиссии оператора платформы цифрового рубля.
* Отражения операций с физическими и юридическими лицами.
* Пополнение и вывод денежных средств по счету цифрового рубля.
* Прочие операции с оператором платформы цифрового рубля.

По остальным система выдаст
сообщение, что операция не поддерживается.

В документе **Списание безналичных ДС** наименование поля **Номер по банку** изменено на **Идентификатор**
при использовании цифрового счета организации. Длина поля **Идентификатор** увеличена до 36 символов.

![](image013.png?_=000283D7D12A9FAE-v10)

Аналогично в документе **Поступление безналичных ДС**, длина поля **Идентификатор** увеличена до 36 символов.

![](image015.png?_=0001E34A403208F4-v10)

Поле **Счет
получателя** необязательно для заполнения для операции **Прочий расход** со счетом цифрового рубля.

![](image017.png?_=0002DCD7DAE8C73B-v10)

Поле **Номер
счета** для счета цифрового рубля физического лица необязательно для
заполнения. При отсутствии в выписке сведений о банке по умолчанию заполняются
данные оператора платформы цифрового рубля.

**![](image019.png?_=00024D889BB8E5C4-v10)**

При загрузке выписки
цифрового рубля автоматически подбираются бюджетные реквизиты.

![](image021.png?_=0002BC5904CBDA86-v10)

Ниже в таблице показан
алгоритм подбора бюджетных реквизитов.

|  |  |  |  |
| --- | --- | --- | --- |
| Тип налога/ХО | Ключевое слово в назначении платежа | КБК | ОКТМО |
| Тип налога «Страховые взносы от несчастных случаев» | «взносы», «травматизм», «СФР», «несчастные случаи» | 79710212000062200160 - процент 79710212000062100160 - пени  79710212000063000160 - штраф  79710212000061000160 | вручную |
| Операция **Таможенный платеж** | «авансовые платежи» + «ФТС» / «таможенных» | 15301061301010000510 | 45328000 |

Реквизиты, которые меняются в
каждом платеже, такие как период, **Номер** документа,
дата документа заполняются по умолчанию.

Бюджетные реквизиты по
остальным операциям перечисления в бюджет, не указанные в таблице, заполняются
по аналогичным платежам, либо необходимо заполнить самостоятельно.

В поле **Счет
отправитель** подбирается единственный доступный счет цифрового рубля

#### Ограничения

* Реквизиты
  бюджетного платежа по приказу Минфина России [от 16.05.2025 № 58н](/db/garant/content/411974682/hdoc) поля 101–109:
  КБК, ОКТМО, Основание, Период, Номер и Дата документа-основания - не
  передаются. Автоматическое заполнение этих реквизитов при загрузке операций
  перечисления в бюджет выполняется путем поиска и подбора возможных вариантов -
  по истории предыдущих платежей с теми же плательщиком, получателем и типом
  налога, либо частично по типу налога (только КБК). Если подбор не дал результата,
  документ не проводится и необходимо заполнить реквизиты вручную.
* Выгрузка
  платёжных поручений и иных платёжных документов из системы в банк для счёта
  цифрового рубля не поддерживается ни в одном из существующих форматов
  (1CClientBankExchange, ДиректБанк). Формат выгрузки на платформу цифрового
  рубля находится в стадии разработки. Ручные платёжные документы, у которых
  одной из сторон выступает счёт цифрового рубля, исключаются из выгрузки
  автоматически. Оформление таких операций выполняется пользователем через личный
  кабинет или приложение банка. В систему загружается история уже совершённых
  операций через выписку.
