## Регламентированный учет

### Подтверждение расходов при казначейском сопровождении государственных контрактов

Форма и алгоритмы заполнения
отчета **Подтверждение расходов при казначейском
сопровождении** (меню **Регламентированный учет -
Отчеты**) приведены в соответствие положениям Приказа Минфина России [от 10
декабря 2021 г.
N 210н](/db/garant/content/403225140/hdoc) в редакции Приказа Минфина России [от 27.06.2025 N 83н](/db/garant/content/412300208/hdoc) (далее – Приказ
210н). Отчет за любой период теперь формируется по этим формам и алгоритмам.

Подержано формирование отчета
**Подтверждение расходов при казначейском сопровождении**
не только отдельно по головной организации и обособленным подразделениям, но и в
целом по организации с учетом данных обособленных подразделений. Для этого в
поле выбора организации добавлены значения вида «Организация **с обособленными подразделениями**».

![](image001.png?_=0000D61DEDD7EABC-v10)

Показатели отчета **Подтверждение расходов при казначейском сопровождении**
заполняются по элементам списка **Направления расходования
целевых средств**: для показателей отчета в алгоритмах системы описан
список относящихся к нему кодов указанного списка. Актуализированы списки кодов
для показателей отчета.

В шапке отчета **Подтверждение расходов при казначейском сопровождении**
удалена гиперссылка **Плановые затраты по госконтракту**.
Переход к регистру **Плановые затраты по государственным
контрактам**, из которого в отчет берутся плановые данные по контракту,
доступен из карточки элемента списка **Направления
деятельности**.

![](image003.png?_=00019DA8979DEDF3-v10)

Добавлены расшифровки
показателей отчета **Подтверждение расходов при
казначейском сопровождении** до оборотов и расшифровки оборотов до
регистраторов. Расшифровка показателей отчета с использованием стандартного
бухгалтерского отчета **Обороты счета** исключена.

![](image005.png?_=000202FE2C025B77-v10)

![](image007.png?_=000133C988749D49-v10)

В алгоритмах формирования
отчета **Подтверждение расходов при казначейском
сопровождении** при получении данных по постатейным расходам учтено, что в
отчет должны попадать только расходы по статьям, в которых выбрана статья
калькуляции с установленным признаком **Учитывать при
формировании цены продукции ГОЗ** или непосредственно в карточке статьи
расходов установлен указанный признак.

![](image009.png?_=00048562832914E0-v10)

Поддержано заполнение отчета **Подтверждение расходов при казначейском сопровождении**
при использовании организацией функциональности повышенной детальности
регламентированного учета. Адаптированы алгоритмы формирования показателей
отчета, собираемых по оборотам на счетах бухгалтерского учета, в т.ч. к
ситуации, когда дата включения функциональности повышенной детальности
регламентированного учета находится внутри периода формирования отчета.

Алгоритмы заполнения отчета:

* Старый – алгоритм
  версии до обновления (для сравнения);
* Без детализации
  –функциональность повышенной детальности регламентированного учета в информационной
  базе выключена;
* С детализацией
  (устаревшие счета) - функциональность повышенной детальности
  регламентированного учета в информационной базе включена, но в отчет собираются
  данные за период до даты ее включения;
* С детализацией -
  функциональность повышенной детальности регламентированного учета в
  информационной базе включена и в отчет собираются данные за период с даты ее
  включения.

Общие отборы для всех
алгоритмов отчета:

* Отбор оборотов
  счета по направлению деятельности, которое выбрано в отчете (далее – НД);
* Отбор оборотов
  счета по пустому направлению деятельности (далее – Без НД);
* Отбор оборотов
  счета по всем направлениям деятельности, кроме того, которое выбрано в отчете
  (далее – Иное НД)

Ограничения

Адресные работы сторонних подрядчиков по контракту
должны отражаться по номенклатуре работ. Их отражение по статьям расходов не
применяется.

С обособлением сбора затрат под направление
деятельности, соответствующее рассматриваемому государственному контракту на
казначейском сопровождении, должны оформляться производственные задания
(документы **Производство
без заказа**, **Заказ на
производство**) на все виды проводимых в рамках контракта работ за исключением сбора
затрат по объектам капитального строительства.

Стоимость всех материалов, относимых по схеме номенклатурных
затрат в состав прямых производственных затрат по заказам на производство,
всегда участвует в ценообразовании продукции контракта, т.е. для таких
материалов в составе производственной себестоимости не применяются статьи
калькуляции со снятой галочкой **Учитывать при формировании цены продукции ГОЗ**.

Начисленная заработная плата основных исполнителей
всегда относится к расходам, учитываемым при ценообразовании продукции
контрактов.
