## Казначейство

### Учет операций по платежным картам (платежным системам)

Федеральным законом от 28.11.2025 № 425-ФЗ вступят в силу
поправки в статью 149 НК РФ, которые упраздняют освобождение от НДС,
применяемое в отношении операций и услуг по обслуживанию банковских карт (см. [здесь](https://buh.ru/news/uslugi-po-obsluzhivaniyu-bankovskikh-kart-budut-oblagatsya-nds.html)).

Для целей учета НДС с банковской комиссии требуется изменить
порядок учета самой комиссии банка. До вступления в силу указанных требований
комиссии сразу отражалась на прочие расходы. Для учета НДС с банковской
комиссии сумма комиссии банка вначале отражается как взаиморасчеты с банком с
дальнейшим выделением суммы комиссии без НДС, которая будет отнесена на прочие
расходы, и суммы входящего НДС, которая будет учтена по общим правилам.

В форме договора подключения к платежной системе на закладке
**Расчеты** предусмотрен переключатель, определяющий
порядок отражения комиссии в учете:  **Списывать на расходы** или **Учитывать
во взаиморасчетах**, которая позволяет учесть сумму комиссии с выделением
НДС.

![](image001.png?_=0000A568B8BD996E-v10)

При выбранном значении **Списывать на
расходы**, которое соответствует порядку отражения комиссии в предыдущих
версиях на закладке **Учетная информация** карточки
договора подключения к платежной системе указывается подразделение, статья и
аналитика расходов, направление деятельности (Зависит от используемой
функциональности). Вся сумма комиссии сразу списывается на расходы документом,
в котором указывается комиссия (определяется соответствующей настройкой в
договоре подключения).

При выбранном значении **Учитывать во взаиморасчетах**
на закладке **Учетная информация** карточки договора
подключения к платежной системе указывается **Объект
расчетов комиссии** – элемент справочника **Договоры с
контрагентами** с видом  договора **с поставщиком**. По указанному договору будет отражаться
взаиморасчеты с банком по комиссии в документе, в которым отражается сумма
комиссии (определяется соответствующей настройкой в договоре подключения).

![](image003.png?_=000074697EECBF8A-v10)

В зависимости от настроек в форме договора подключения к
платежной системе на закладке **Расчеты** комиссия
отражается:

* **В отчете банка /
  платежной системы**

![](image005.png?_=00006B260AB8E337-v10)

* **При зачислении на
  банковский счет**

![](image007.png?_=0000B4EE784ED12F-v10)

* **В транзакции оплаты**
   (**Эквайринговая
  операция**, **Операция по ЮKassa**)

![](image009.png?_=00009CBEC4CC55F1-v10)

* **В отдельном
  списании с расчетного счета**

![](image011.png?_=0000BF2C52F53E51-v10)

Взаиморасчеты с банком отражаются по дебету счета расчетов,
указанном в ГФ расчетов (по умолчанию 76.05), в корреспонденции со счетом
денежных средств в пути (57.03).

Общая сумма начисленной комиссии будет видна во всех отчетах
по взаиморасчетам.

Обязательства банка закрываются документом **Приобретение товаров и услуг** или
**Приобретение
услуг и прочих активов**. В документе выделяется НДС. Сумма комиссии без
НДС списывается на указанную в документе статью расходов. НДС относится на счет
19.04 и далее принимается к вычету по общему правилу.

## Регламентированный учет

### Классификация выручки по ОКВЭД

Согласно Федеральному закону от 28.12.2024 № 529-ФЗ и
Постановлениям Правительства от 23.05.2025 № 717, от 27.05.2025 № 728 коды
ОКВЭД, указанные в статистической отчетности, могут быть использованы при
определении Росстатом основного вида деятельности организации, по которому
Социальный фонд России с 2026 года устанавливает тариф страховых взносов от
несчастных случаев на производстве. Для выполнения требований указанных
Постановлений необходимо использовать коды ОКВЭД с указанием не менее четырех
цифровых знаков.

Для обеспечения возможности распределить выручку организации
по кодам ОКВЭД добавлен новый отчет **Классификация выручки
по ОКВЭД**. Отчет доступен в формах статистической отчетности
1-предприятие «Основные сведения о деятельности организации» и П-1 «Сведения о
производстве и отгрузке товаров и услуг» и в меню **Регламентированный
учет – Сервис**. Возможность ручной настройки отборов заполнения по кодам
ОКВЭД из указанных статистических отчетов исключена. Коды, указанные для
определенных видов деятельности, записываются в правила заполнения форм и
используются в дальнейшем.

Варианты перехода к отчету **Классификация
выручки по ОКВЭД** из статистических форм приведены на рисунке.

![](image015.png?_=000170FE02672877-v10)

В отчете **Классификация выручки по ОКВЭД** по кнопке **Настройки** можно настроить порядок и состав требуемых
группировок отчета, а также установить нужные отборы. Работа с настройками
аналогична другим типовым отчетам. Ограничением настройки для установки кода
ОКВЭД является то, что количество полей группировок должно быть не более 5
(пяти).

![](image017.png?_=00017D714D194113-v10)

По умолчанию вся выручка относится к коду ОКВЭД, указанному
в карточке организации, по которой строится отчет. Если есть номенклатура услуг
и она была классифицирована для контролируемых сделок, то берется код ОКВЭД2 из
карточки номенклатуры.

![](image019.png?_=000479597678AB8C-v10)

По команде **Установить код ОКВЭД**,
доступной в контекстном меню (левая кнопка мыши на требуемой группировке отчета),
можно установить/изменить код для группировки отчета. Если клик левой кнопкой
мыши сделан в колонке, где выведено поле не ссылочного типа (например, ОКВЭД,
сумма выручки), то форма **Установка кода ОКВЭД**
откроется без выбора команды в дополнительном контекстном меню. Форма **Установка кода ОКВЭД** открывается с набором полей,
соответствующим выбранной группировке отчета. При этом все поля указанной формы
недоступны для изменения, можно только выбрать и сохранить код ОКВЭД для данной
группировки.

![](image021.png?_=000288F32E9E0B23-v10)

Для организации можно настроить ОКВЭД только по одному
составу группировок. Если по организации после внесения настроек заполнения
кода ОКВЭД поменялся состав группировок и делается попытка изменить коды ОКВЭД,
программа выдаст соответствующее предупреждение при вызове команды **Установить код ОКВЭД**. При изменении порядка или состава
группировок отчета ранее сохраненные настройки на данный период будут очищены.

![](image023.png?_=0001D95BDEC9F92C-v10)

Формы статистической отчетности 1-предприятие «Основные
сведения о деятельности организации» и П-1 «Сведения о производстве и отгрузке
товаров и услуг» заполняются в соответствии с настроенным в отчете **Классификация выручки по ОКВЭД** распределением выручки по
кодам.

![](image025.png?_=00009375E127E5E4-v10)

Ограничение

В группировке отчета на одном уровне
должно быть добавлено только одно поле. Иначе отчет сформируется с данными по
выручке, но без данных по ОКВЭД, т.к. нет понимания приоритета полей

### Расширение номенклатуры форм регламентированной отчетности

В состав форм регламентированной отчетности добавлены:
• форма статистики № 1-ТОРГ (МО) "Сведения об объектах розничной торговли
и общественного питания" (ОКУД 0614026) (утверждена приказом Росстата от
08.04.2025 № 176).  
Форма применяется начиная с отчета за 4 квартал 2023 года.  
Сроки предоставления: с 13 по 20 января после отчетного года.

Внимание!

В состав форм регламентированной отчетности добавлена
тестовая форма декларации по налогу на доходы физических лиц (форма 3-НДФЛ),
утвержденная приказом ФНС России от 20.10.2025 № ЕД-7-11/913@.  
В тестовую форму 3-НДФЛ могут быть внесены изменения в последующих версиях
программы.  
Новая форма применяется начиная с отчета за 2025 год.  
Для использования новой редакции формы 3-НДФЛ, в списке отчетов при создании
нового отчета следует выбирать строку "3-НДФЛ (с 2025 года)".
