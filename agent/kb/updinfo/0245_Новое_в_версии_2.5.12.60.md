## Регламентированный учет

### Налог на имущество

Изменился формат xml расчета налога ФНС. В новом варианте формата по каждому объекту может
быть несколько строк с данными расчета в зависимости от действующих параметров расчета по периодам.
Отчет "Справка-расчет налога на имущество" доработан таким образом, чтобы облегчить
сверку с ФНС. Теперь будет выводиться по несколько строк на объект.
