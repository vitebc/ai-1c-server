## Интеграция с Государственной информационной системой маркировки «Честный знак»
### Поддержка API СУЗ версии 3

Реализована поддержка API СУЗ версии 3.0. С 01.06.2024 ГИС
МТ планирует прекращение поддержки API СУЗ v2, а с 01.09.2024 - вывод API СУЗ
v2 из эксплуатации.

В API СУЗ версии 3.0 в том числе, увеличено максимальное
количество кодов маркировки в заказе до 2 миллионов на одну товарную позицию
(код товара, GTIN). При заказе более 150 000 кодов на одну товарную позицию, в
заказе должна присутствовать только одна товарная позиция.

Для использования API СУЗ 3, необходимо изменить формат
обмена в соответствующей станции управления заказами. **Параметры подключения к СУЗ** указываются в разделе НСИ и
администрирование – Настройка интеграции – Интеграция с ИС МП (обувь, одежда,
табак…).

### Вывод из оборота

Для товарной группы **Медицинские
изделия** в документе **Вывод из оборота
ИС МП** предусмотрена причина вывода из оборота **Использование для медицинского применения**.

и **Антисептики** в документе **Вывод из оборота ИС МП** предусмотрено
причина вывода из оборота **Корректировка
остатков ОСУ**.

### Списание кодов маркировки

Для товарных групп **Табак**,
**Альтернативная табачная продукция**, **Никотиносодержащая продукция** добавлены
новая причина списания **Использование для
собственных нужд с уплатой акциза**.

Для всех товарных групп кроме Морепродукты, Продукция из
натурального меха, предусмотрена новая причина списания **Выбытие до обязательности маркировки**.

При оформлении списания кодов маркировки для товарных групп **Табак**, **АТП**, **НСП** обязательно
указание адреса производственной площадки.

Для товарной группы Пиво обязательно указание кода ФИАС.

Для всех товарных групп доступно указание причины списания в
шапке документа. Также причина списания может быть указана в таблице **Товары**. При подготовке данных для
передачи в ГИС МТ причина, указанная в таблице **Товары**, будет иметь более высокий приоритет при заполнении данных
по строке.

### Уточнение сведений о кодах маркировки ИС МП

В документе **Уточнение
сведений о кодах маркировки ИС МП** для операции **Корректировка сведений о кодах** для всех товарных групп на странице **Разрешительная документация**
предусмотрен реквизит **Режим обновления
разрешительной документации**», который принимает следующие значения:

●
**добавить
новые сведения к существующим в ЛК**

●
**заменить
сведения в ЛК на указанные в документе**

Для товарной группу Упакованная вода на странице **Разрешительная документация**
предусмотрена таблица **Лицензии на
пользование недрами**. Обновления сведений о лицензиях работает аналогично
обновлению сведений о разрешительной документации

В документе **Уточнение
сведений о кодах маркировки ИС МП** для операции **Корректировка сведений о ВСД и сроке годности** возможно указание
кодов со статусами **Выбыл** и **Списан**. Недоступно изменение сведений о
кодах, имеющих особое состояние. При сканировании кода, имеющего особое
состояние, будет выдано предупреждение.

●
**выявлены

В документе **Приемка
товаров ИС МП** загружается вес. Для номенклатуры с весовой единицей будет пересчитано
количество.

### Агрегация

При выполнении агрегации доступно указание в качестве
вложений потребительских кодов, имеющих состояние **Ожидает передачу собственнику (контрактное производство)**.

Для товарных групп **Табак**,
**Альтернативная табачная продукция**, **Никотиносодержащая продукция** недоступно
указание кодов со статусом **Не оплачен**
как в качестве агрегата, так и в качестве вложений.

### Контроль остатка пива в кегах

При
продаже пиво из кег необходимо отправлять информацию о постановке кега на кран
в течение 24 часов с первой продажи пива данного кега. В целях своевременного
исполнения данного требования при продаже пива на розлив в РМК реализован
контроль передачи информации о постановки кега на кран и остатка пива в кеге.

При
продажах пиво на розлив в РМК возможно два сценария работы:

■ Каждое
наименование пива может быть подключено только к одному крану

■ Каждое
наименование может быть подключено к нескольким кранам

#### Сценарий «Наименование пива на одном кране»

В этом случае в РМК достаточно только добавить номенклатуру
любым из предусмотренных способов: Используя "горячие клавиши" **Быстрые товары** (рекомендуется),
сканированием штрихкода EAN-13
или добавление вручную в табличную часть. Код маркировки кега определяется
автоматически согласно отраженному ранее подключению кега к оборудованию
розлива. Если по данному наименованию пива отражено подключение к оборудованию
розлива, то автоматически предлагается отразить подключение кега к
оборудованию.

Если кег подключен, то также проверяется расчетный остаток
пива в кеге.

Если расчетный остаток пива в кеге меньше указанного в строке
количества к продаже, то к описанию товара в верхней части формы добавляется
сообщение о недостаточном для продаже количестве с указанием текущего
расчетного остатка в кеге.

![](image007.png?_=0000808AF4B6F99B-v10)

Если расчетный остаток пива в кеге больше указанного в
строке количества, но остаток за вычетом количества в чеке меньше либо равно 5
л, то к описанию товара в верхней части формы добавляется сообщение с указанием
текущего расчетного остатка в кеге.

![](image009.png?_=000080DAB41FC247-v10)

Если по наименованию пива расчетный остаток в кеге за
вычетом количества в чеке больше 5 л, то дополнительной информации к описанию
товара не выводится.

#### Сценарий «Наименование пива на нескольких кранах»

Если
одно наименование пива подключено к нескольким кранам, то при добавлении товара
потребуется уточнить, с какого именного крана (из кега с каким кодом
маркировки) осуществляется розлив пива. Для этого используется форма уточнения
данных

![](image011.png?_=00004D8D462CA95F-v10)

В случае указания количества больше расчетного остатка по
кегу, отображается сообщение о превышении.

![](image013.png?_=000041A9D092040B-v10)

После
выбора крана или кода маркировки, данные добавляются в таблицу **Товары** и таблицу **Акцизные марки**. Колонка **Количество**
таблицы товары в данном случае недоступна на редактирование. При остатке за
вычетом продажи менее 5 литров выводится информация о текущих остатках по
кегам.
