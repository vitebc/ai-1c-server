## Регламентированный учет

### Контролируемые сделки

В функциональности
системы по подготовке и отправке в ФНС документации по контролируемым сделкам
выполнены доработки в соответствии с Письмом ФНС России [от 20.01.2026 №
13-4-03/0001@](/db/garant/content/413493630/hdoc), в котором определено, что предоставлять документацию необходимо
в центральный аппарат ФНС. Внесены изменения в алгоритм формирования имени
файла с документацией по контролируемым сделкам - код налогового органа, в
котором организация состоит на учете, заменен на код ЦА ФНС России «0023».

### Учет расчетов по ЕНС

Поддержаны рекомендации [БМЦ Р-175/2025-КпР](https://bmcenter.ru/Files/R-KpR_Ediniy_nalogoviy_chet) «Единый налоговый счет» (далее - Рекомендация БМЦ).

При заполнении в составе регламентированной отчетности отчета о
движении денежных средств (далее – ОДДС) единый налоговый платеж (далее – ЕНП)
показывается общей суммой по всем налогам. При использовании организацией
встроенной и настраиваемой отчетности можно выделить в отдельные строки уплату
НДФЛ и налога на прибыль. В настраиваемой отчетности дополнительно можно
настроить развернутое представление НДС.

Согласно п. 2 Рекомендации БМЦ организация представляет в ОДДС и
пояснениях к нему общую сумму платежа по всем налогам, сборам и иным
обязательным платежам, расчеты по которым осуществляются через единый налоговый
счет, т.н. «простой вариант». При этом НДС, выделенный из потоков покупателей и
поставщиков, сворачивается и вычитается из потока ЕНП. При использовании «простого
варианта» отражения ЕНП в ОДДС необходимо в документах перечисления налогов
использовать статьи движения денежных средств с видом движения денежных средств
«Единый налоговый платеж».

![](image001.png?_=000144CE507870FE-v10)

Во встроенной отчетности для сроки 4124 автоматически будет
добавляться новая подстрока, в которую будут попадать денежные потоки по виду
движения денежных средств «Единый налоговый платеж».

![](image003.png?_=0001539BF5F15782-v10)

Для настраиваемой отчетности новая строка с отбором по виду
движения денежных средств «Единый налоговый платеж» добавлена в поставляемые
правила.

Согласно п. 3 Рекомендации
БМЦ организация может распределять ЕНП по видам налогов, исходя из
самостоятельно установленного обоснованного метода, который раскрывается в
бухгалтерской отчетности, т.н. «развернутый вариант». Для распределения ЕНП в
ОДДС по видам налогов необходимо разбивать платеж по разным статьям движения
денежных средств с видами движения денежных средств, соответствующими
уплачиваемым налогам. Для выделения из ЕНП уплачиваемых НДФЛ и налога на
прибыль необходимо использовать статьи движения денежных средств с видами движения
денежных средств «Оплата труда» и «Налог на прибыль» соответственно.

Для выделения из ЕНП уплачиваемого НДС
добавлен новый вид движения денежных средств «Уплата НДС». НДС, выделенный из
потоков покупателей и поставщиков, сворачивается и сальдируется с потоком
уплаты НДС. В поставляемые правила строка с таким видом ДДС не добавлялась. В
случае необходимости такую строку в настройки заполнения отчетности пользователю
надо добавить вручную.

![](image005.png?_=000068B8EBDA0755-v10)

Выделение НДС из ЕНП в ОДДС поддержано только для настраиваемой
отчетности.

![](image007.png?_=00014EE85D2B7F72-v10)
