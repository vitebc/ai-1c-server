## Закупки

### СПОТ/Присвоение РНПТ в ДОПП

Поддержан учет прослеживаемых
товаров по РНПТ при ввозе из ЕАЭС без подачи уведомления о ввозе прослеживаемых
товаров. Номера РНПТ на прослеживаемые товары будут присваиваться в ДОПП.

* С 1 октября на прослеживаемые товары, указанные в ДОПП, будут присваиваться номера РНПТ.
* РНПТ
  присваивается только тем прослеживаемым товарам, по которым в ДОПП установлен
  «Особый признак» <ОсобПризн> «0» (признак отсутствует). По таким позициям
  предоставлять уведомление о ввозе прослеживаемых товаров не нужно.
* Если количество
  поступивших товаров больше, чем указано в ДОПП, то дополнительно представляется
  стандартное уведомление о ввозе, в котором отражается ввезенный (принятый к
  учету) товар, ранее не указанный в ДОПП.
* Если количество
  поступивших товаров меньше, чем указанно в ДОПП, то представляется
  корректировочное уведомление, в котором отражается только позиция с выявленным
  расхождением. Кроме того, в таком уведомлении (далее – уведомление о
  корректировке ДОПП) указывается номер корректировки «0», что отличает его от
  обычного корректировочного уведомления. При этом на каждый сформированный РНПТ
  необходимо формировать отдельное уведомление о корректировке ДОПП.
* Если товар не
  ввезен на территорию РФ, нужно представить уведомление о корректировке ДОПП с
  указанием количества товаров «0». В этом случае присвоенный по обеспеченному
  ДОПП РНПТ будет исключен из оборота.
* Уведомления о корректировке ДОПП нужно будет представлять с 1 декабря 2026 г.

#### Документ о предстоящей поставке

В ДОПП добавлены новые поля:

* **Заказ поставщику**. При
  создании ДОПП на основании заказа поставщику строки товаров будут привязаны к
  заказу. Добавить строку в ДОПП из заказа можно по команде **Подобрать товары по заказам**. Если ДОПП был оформлен на
  основании заказ поставщику, для «старых» документов реквизит заполнится
  обработчиком обновления. Если ДОПП по заказу поставщику, то при добавлении
  строки по команде **Добавить** строки будут считаться
  сверх заказа, поэтому для таких строк будет устанавливаться признак ![](image001.png?_=0000030A1D8880A8-v10).
* **РНПТ**. Заполняется номер РНПТ для прослеживаемых импортных товаров, присвоенный по ДОПП.
* **Количество по РНПТ**. Заполняется
  для прослеживаемых импортных товаров. Для «старых документов» заполнится
  обработчиком обновления для строк с прослеживаемыми товарами.

![](image003.png?_=0000FAC24CFAE3A7-v10)

РНПТ присваивается на
основании представленного в СПОТ ДОПП, по которому внесен обеспечительный
платеж и получен QR-код (далее – обеспеченный ДОПП). Присвоенный РНПТ нужно
внести в ДОПП.

Если подключена 1С:Отчетность,
то в ДОПП:

* РНПТ заполняется автоматически из квитанции ФНС при ее получении.
* Либо можно
  заполнить РНПТ по команде **Заполнить РНПТ из квитанции ФНС**
  (команда доступна, если подключена 1С:Отчетность).

![](image005.png?_=0001D90F2BDBA3A3-v10)

Установить РНПТ для нескольких
строк можно по команде **Установить РНПТ**. Для
выделенных строк будет заполнен РНПТ, который уже есть в справочнике «Номера
ГТД», если такого РНПТ нет, то будет создан новый РНПТ по указанной стране
происхождения.

Для установки РНПТ
обязательно должна быть заполнена страна происхождения в ДОПП, которая
используется для формирования номера РНПТ.

![](image007.png?_=00010B9ADECF30D3-v10)

#### Приобретение товаров и услуг с операцией «Ввоз из ЕАЭС»

Для прослеживаемых товаров,
для которых был присвоен РНПТ при подаче ДОПП, в документе **Приобретение товаров и услуг** с операцией **Ввоз из ЕАЭС** нужно будет заполнить номер РНПТ. Для строк
с РНПТ не будет формироваться распоряжение на оформление уведомления о ввозе
прослеживаемых товаров.

Для строк с прослеживаемыми
товарами, для которых РНПТ останется пустым в документе **Приобретение
товаров и услуг**, будет формироваться распоряжение на оформление
уведомления о ввозе прослеживаемых товаров.

![](image009.png?_=0000CC1FAC56DE50-v10)

Если **Приобретение
товаров и услуг** создается на основании ДОПП, РНПТ заполнится
автоматически по данным ДОПП.

Если приобретение заполняется
на основании заказа поставщику, то номер РНПТ будет автоматически подобран по
остаткам номеров, указных в ДОПП. При необходимости можно перевыбрать вручную
РНПТ.

Если приобретение заполняется
вручную, то номер РНПТ можно выбрать из списка РНПТ, по которым были оформлены
ДОПП, но еще не были оформлены приобретения. РНПТ подбираются по полям:

* Договор.
* Заказ поставщику.
* Номенклатура.
* Характеристика номенклатуры.

Установить РНПТ для
выделенных строк можно по команде **Номера ГТД - Заполнить
РНПТ**, которая доступна в приобретении товаров и услуг только для
операции **Ввоз из ЕАЭС**.

![](image011.png?_=0000D9A4E04B89D5-v10)

* Если количество
  поступивших товаров больше, чем указано в ДОПП, то строку товаров в
  приобретении товаров и услуг нужно разбить на две. В одной (с количеством как в
  ДОПП) указывается РНПТ, во второй (с количеством превышения) РНПТ не
  заполняется. На строку с пустым номером РНПТ будет сформировано распоряжение на
  создание уведомления о ввозе прослеживаемых товаров. Если строку не разбить, то
  документ **Приобретение товаров и услуг** не
  проведется, поскольку остатков по указанному РНПТ будет недостаточно.
* Если количество
  поступивших товаров меньше, чем указанно в ДОПП, то приобретение с указанием
  РНПТ оформляется на фактическое количество.
  На разницу в дальнейшем нужно будет сформировать корректировочное уведомление.
  Но до 1 декабря 2026 г.
  такие позиции пока остаются «висеть» в программе. Ничего дополнительно
  оформлять не требуется.
* Пересорт: в ДОПП
  указана не та номенклатура, что поступила фактически на склад, но при этом не
  хотим получать новый номер РНПТ, поскольку есть право использовать существующий
  РНПТ. В этом случае нужно вернуться в ДОПП и исправить в нем номенклатуру и/или
  характеристику.
* Если поставка
  отменилась. В ДОПП РНПТ обязательно должны быть указаны. По этим номерам РНПТ с
  1 декабря 2026 г.
  нужно будет формировать корректировочное уведомление и снимать эти
  прослеживаемые товары с учета.

#### Корректировка приобретения с операцией «Ввоз из ЕАЭС»

В документе **Корректировка приобретения** с операцией **Ввоз из ЕАЭС** можно вручную указать номер РНПТ.

Для прослеживаемых товаров,
поступивших сверх ДОПП, нужно вносить отдельную строку и оставлять в ней РНПТ
пустым.

## Регламентированная отчетность

### Расширение номенклатуры форм регламентированной отчетности

В состав форм
регламентированной отчетности добавлены:

* Отчет о фактических затратах по государственному контракту, контракту,
  заключенному в рамках государственного оборонного заказа (утвержден
  Постановлением Правительства РФ [от 13.07.2026 № 874](/db/garant/content/414473102/hdoc));
* форма статистики [№ 1-предприятие](/db/garant/content/414756044/hdoc/1000) "Основные сведения о деятельности
  организации" (ОКУД 0601009) (утверждена приказом Росстата от 31.07.2026 №
  423);  
  Форма применяется начиная с
  отчета за 2026 год.  
  Сроки предоставления: с 1 марта по 1 апреля после отчетного периода.
* форма статистики [№ МП (микро)](/db/garant/content/414756044/hdoc/3000) "Сведения об основных показателях
  деятельности микропредприятия" (ОКУД 0601016) (утверждена приказом
  Росстата от 31.07.2026 № 423).  
  Форма применяется начиная с
  отчета за 2026 год.  
  Сроки предоставления: с 1-го официального рабочего дня января по 5 февраля.

### Изменения в формах регламентированной отчетености

В декларацию по акцизам на
автомобильный бензин, дизельное топливо, моторные масла для дизельных и (или)
карбюраторных (инжекторных) двигателей, прямогонный бензин, средние дистилляты,
бензол, параксилол, ортоксилол, авиационный керосин, природный газ, автомобили
легковые и мотоциклы в редакции приказа ФНС России [от 12.10.2022 № ЕД-7-3/923@](/db/garant/content/405962591/hdoc)
внесены изменения в соответствии с письмом ФНС России [от 11.09.2026 №
СД-36-3/8023@](/db/garant/content/414822260/hdoc).  
  
Для формы "Реестр документов (чеков) для компенсации суммы налога,
предусмотренный пунктом 3.10 статьи 165 Налогового кодекса Российской
Федерации" (КНД 1155217)в редакции приказа ФНС России [от 08.12.2020 №
КЧ-7-15/886@](/db/garant/content/400098626/hdoc) реализована выгрузка в формате версии 5.03, рекомендованном
письмом ФНС России от 24.07.2026 № СД-36-15/6381@.

### Изменения в электронном представлении форм регламентированной отчетности

Для формы статистики [№ 1-ИП
(торговля)](/db/garant/content/412487526/hdoc/6000) "Сведения о деятельности индивидуального предпринимателя в
розничной торговле" (ОКУД 0614019) (утверждена приказом Росстата от 28.07.2025
№ 365) реализована выгрузка в электронном виде в соответствии с XML-шаблоном от
24.08.2026 (редакция от 24.09.2026).
