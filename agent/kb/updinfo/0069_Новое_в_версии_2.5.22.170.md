### Интеграция с ГИС МТ ("Честный знак")

#### Изменение состава товарных групп

Согласно Постановлению Правительства [от 31.01.2026 № 75](/db/garant/content/413465912/hdoc) для
меховых изделий меняются правила маркировки. Взамен технологии с маркировки
товаров из натурального меха с использованием контрольных (идентификационных)
знаков (КиЗ) утверждены правила маркировки с использованием кодов DataMatrix. С 1 марта 2026
года маркировка меховых изделий производителями и импортерами должна выполнятся
по новым правилам. Также с 1 марта 2026  необходимо
передавать сведения об оптовых и розничных продажах, а также об ином выводе из
оборота по меховым изделиям, маркируемым по новым правилам.

Продажа остатков меховых изделий, маркированных КиЗ, и не
имеющих маркировку DataMatrix Code, будет разрешена по
28 февраля 2027 года.

Для работы с меховыми изделиями по новым правилам необходимо
установить флаг товарной группы **Натуральный мех** в
форме настроек в таблице **НСИ и администрирование –
Настройка интеграции – Интеграция с ИС МП (одежда, обувь, табак…) – Вести учет
маркируемых товаров**, а также создать новый вид номенклатуры с
особенностью учета **Натуральный мех** и новые
карточки номенклатуры. Существующие карточки номенклатуры с особенностью учета
**Товары из натурального меха** продолжают использоваться до
выбытия запасов, маркированных по старым правилам.

Для товарной группы **Натуральный мех**
предусмотрено оформление **Заказа на эмиссию кодов
маркировки СУЗ** с видами операций: **Производство в
РФ**, **Импорт в РФ**, **Маркировка
вне производства или импорта**. Предусмотрен заказа кодов для **Единицы товара** и для
**Набора**.

После нанесения кодов маркировки требуется передача **Отчета о верификации нанесенных КМ** документом
**Маркировка товаров ИС МП**, которая может выполняться
независимо или совместно с операцией ввода в оборот. Предусмотрены следующие

#### Поддержка версии 2.х Локального модуля "Честного знака"

Реализована возможность работы с Локальными модулями версий V1 и новой версии V2

Реализован контроль минимальной розничной цены, возвращаемой
ГИС МТ в разрешительном режиме, по никотиносодержащей продукции при пробитии чека.
Контроль возможен только с версии ЛМ 2.х. Если при пробитии цена НСП менее
установленной минимальной цены, возвращенной ГИС МТ – при проверке средствами
ККТ выдается ошибка.

Версия устанавливается в настройках подключения ЛМ ЧЗ
(реквизит Формат обмена).

![](image001.png?_=00007180CF8E4298-v10)

При обновлении по всем имевшимся настройкам подключения ЛМ
ЧЗ устанавливается единственно возможный ранее формат обмена V1. Для версии 1 выводится подсказка о
необходимости перехода на версию 2.

Для перехода с формата V1 на формат V2 необходимости полного
удаление старой версии ПО ЛМ ЧЗ и установки новой версии на ПК. При изменении
формата в настройках ЛМ ЧЗ в информационной базе выдается соответствующее предупреждение.

Установленный экземпляр Локального модуля необходимо заново
инициализировать по ссылке Запустить процесс настройки в настройках
подключения.

![](image003.png?_=000056F32BF258A0-v10)

После успешной инициализации на месте ссылки уде отображено сообщение
о корректности настройки Локального модуля и дальнейшей возможности его
использования.

#### Учет маркируемой продукции по местам осуществления деятельности

Для отдельных товарных групп предусмотрен учет по местам
осуществления деятельности (МОД). МОД – это в частности склад или
подразделение, в котором находится товар.

С 1 марта 2026 года вступили в силу требования Постановления
Правительства РФ [от 27 мая 2024
г № 675](/db/garant/content/409013340/hdoc) по отслеживанию перемещения продукции товарной
группы **Ветеринарные препараты** между филиалами или
складами одного предприятия и при отгрузке сторонним организациям.

Подобное требование уже действует применительно к Пиву.

Даты начала поэкземплярного учета при оптовых продажах и
начала прослеживаемости перемещений между местами осуществления деятельности
(МОД) указываются в советующих графах по товарной группе В**етеринарные препараты** в форме настроек
**НСИ и администрирование – Настройки интеграции - Интеграция ИС
МП (обувь, одежда, табак…)**

МОД участников оборота регистрируются в ГИС МТ. Если участник оборота юридическое
лицо, то МОД определяется по ИНН и КПП участника оборота – любое территориально
обособленное подразделение подлежит постановке на учет с присвоением кода КПП. Если
участник оборота – индивидуальный предприниматель, то МОД определяется
идентификатором ФИАС (Федеральная информационная адресная система) / ГАР
(Государственный адресный реестр).

Для
товаров, по которым ведется учет по МОД, в случае отгрузки сторонним
организациям необходимо, чтобы МОД получателя был найден по указанному адресу. Предусмотрена
возможность перед отправкой электронного документа выполнить проверку на
соответствие указанных адресов требованиям ГИС МТ. Проверка выполняется по ссылке
**Ожидается проверка УПД в ГИС МТ**, которая отображается в нижней
части документа, рядом со ссылкой, отражающей статус ЭДО.

![](image005.png?_=0000BB0275AD2F5F-v10)

Если в
результате проверки по указанному адресу МОД в ГИС МТ не найден будет
отображена ссылка **Не найден МОД контрагента** и по ней будет предложено
сопоставить адрес с активными доступными МОД по данной товарной группе в ГИС МТ.
После выполнения сопоставления в ЭД будет подставляться ФИАС идентификатор
корректного МОДа получателя.

![](image007.png?_=00015AC83A208FD2-v10)

После успешной
проверке на соответствие требованиям ГИС МТ отображается ссылка **Проверен в ГИС МТ**.

В электронный
документ добавляется тег Покупатель\_ФиасИД, если адрес <ГрузПолуч>
указывается в формате  АдрРФ в
<ГрузПолуч> или ИдНом, если адрес <ГрузПолуч> указывается в формате
<АдрГАР>.

![](image009.png?_=00013865573D29CA-v10)

##### Внутреннее перемещение между МОД

Для
товаров, учитываемых по МОД также необходимо отражение в ГИС МТ фактов
внутреннего перемещения продукции между МОД документом **Перемещение между МОД ИС МП**. Ссылка
**Создать перемещение между МОД ИС МП** отображается в
нижней части документа внутреннего перемещения.

![](image011.png?_=0001203CB6E5AD32-v10)

Документ изначально создается в статусе **Черновик**. В документе указывается вид продукции:

* **Пиво в кегах**
* **Пиво в потребительских упаковках**
* **Ветеринарные препараты**

Примечание

До версии XXXXX по документу Перемещение
между МОД отсутствовало деление по виду продукции, можно было оформлять одно
перемещение и с Пиво в кегах, и с Пиво в потребительских упаковках. В актуальных
версия перемещения по группам **Пиво в кегах** и **Пиво в потребительских упаковках** оформляются раздельно, однако
по ранее оформленным документам без разделения по видам продукции сохраняется
возможность просмотра.

По виду продукции автоматически определяются необходимые
параметры заполнения. В частности  для **Ветеринарных препаратов** требуется указание
**Отправителя**, **Получателя** и **кода ФИАС Получателя**.

По ссылке **оформите перемещение**
документ передается в ГИС МТ. После успешного оформления перемещения статус
документа изменится на **Перемещение оформлено**. В
этом статусе документ блокируется для редактирования, марки переходят на
указанное МОД и можно будет оформлять дальнейшие операции с перемещенными
товарами по новому МОД.
